# QA-план и текущие доказательства

Этот файл отличает автоматические проверки от ручного прохождения. Прохождение до конца, визуальный вид, загрузка Pages и длительность кампании не считаются подтверждёнными по исходникам.

## Автоматический smoke-test

`tests/smoke_test.gd` должен проверять:

- меню и старт сюжетного брифинга;
- наличие `CharacterBody3D`, `Camera3D` и многосоставной mesh-модели корабля;
- столкновение врага с игроком через обновление игрового цикла и блокировку повторного урона во время неуязвимости;
- движение WASD, рывок, паузу и продолжение;
- доступность завершения всех 15 миссий через цель и выходной портал;
- экран окончания кампании, поражение и возврат к контрольной точке.

Результаты и SHA финального коммита фиксируются в GitHub Actions. Текущая цель проверки — успешный Windows x64 export, запуск извлечённого EXE и проверка ZIP.

## Матрица ручного QA

| Проверка | Статус |
|---|---|
| Главное меню, брифинг, управление мышью и клавиатурой | Требует визуального прохождения |
| Пилотирование, столкновение с препятствием, рывок и неуязвимость | Smoke-test + ручное подтверждение |
| Сбор кристаллов и активация узла клавишей F | Smoke-test + ручное подтверждение |
| Пауза, Alt+Tab, победа, поражение и контрольная точка | Smoke-test + ручное подтверждение |
| Визуальное качество 3D-корабля, противников, сцен и эффектов | Требует визуального прохождения |
| ZIP на чистой Windows без Godot/Python/Node и без сети | Требует чистой среды |
| Время нескольких полных прохождений | Не измерено |
| Публикация сайта и доступность Release без авторизации | Не настроено; репозиторий не делался публичным |

## Длительность кампании

Цель — 30–45 минут для первого прохождения. Нельзя выводить фактическое время из числа миссий или автоматического ускоренного сценария. Запишите не менее трёх полных ручных прохождений с версией игры, SHA, временем старта/финиша и итогом; укажите медиану и случаи поражения/повтора. Пока таких протоколов нет, цель не подтверждена.
