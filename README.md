# Lumen Drift — Windows Desktop

Lumen Drift — законченная небольшая аркада на Godot 4. Вы — пилот последнего корабля связи. Пройдите пять секторов, соберите 30 световых ядер, уклоняйтесь от преследователей и снова зажгите маяк.

## Скачать и запустить

Игра распространяется как portable ZIP для **Windows 10/11 x64**. В архиве лежит `LumenDrift.exe` с уже встроенными ресурсами: распакуйте архив и запустите EXE двойным щелчком. Браузер, сервер, Python, Node.js и установленный Godot не нужны.

- [Последняя сборка GitHub Actions](https://github.com/doniel1488-code/ide-game/actions/workflows/windows-build.yml) — откройте последнюю успешную сборку и скачайте `LumenDrift-Windows-x64` в разделе Artifacts.
- [Релизы](https://github.com/doniel1488-code/ide-game/releases) — релизный ZIP публикуется автоматически для тега вида `v1.0.0`.

Минимум: Windows 10 x64 и видеодрайвер с поддержкой OpenGL 3.3. Окно игры открывается в 1280×800, масштабируется при изменении размера и не уменьшается ниже 960×600. Ресурсы игры встроены в EXE; рекорд хранится локально в профиле пользователя.

## Управление

- **WASD** или **стрелки** — движение.
- **Пробел** — рывок с короткой неуязвимостью; шкала вверху показывает перезарядку.
- **Esc** — пауза и продолжение.
- **M** или кнопка «Звук» — процедурные звуковые сигналы.
- Кнопки меню также работают мышью.

Соберите шесть ядер в секторе и коснитесь портала. Три столкновения завершают забег; после удара пилот отбрасывается и ненадолго защищён. Карты и позиции врагов меняются между забегами, опасность растёт по секторам. Между секторами можно передохнуть, а рекорд сохраняется между запусками.

## Разработка и проверка

Проект открыт в [Godot Engine 4.7.2](https://godotengine.org/download/windows/) и использует GDScript, встроенную графику CanvasItem и Compatibility renderer. Внешние игровые ресурсы и runtime-библиотеки не используются.

Для локальной сборки установите Godot 4.7.2 и Windows export templates, затем выполните:

```powershell
godot --headless --path . --quit-after 3
godot --headless --path . --script res://tests/smoke_test.gd
godot --headless --path . --export-release "Windows Desktop" build/LumenDrift.exe
```

GitHub Actions выполняет те же проверки, экспортирует Windows x64 EXE, проверяет его PE-архитектуру, запускает процесс игры на Windows runner и сохраняет ZIP как workflow artifact. Для тегов `v*` тот же архив публикуется как GitHub Release.
