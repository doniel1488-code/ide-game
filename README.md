# Lumen Drift

Сюжетная 3D sci-fi игра на Godot 4. Пять глав, пятнадцать миссий, процедурно собранные low-poly корабль и противники, контрольные точки и локальное сохранение кампании.

## Статус

Игра и сайт находятся в разработке. GitHub Actions проверяет GDScript, игровой цикл и Windows x64 экспорт. Публичный релиз пока не опубликован; не считайте проект готовым, пока последний Windows workflow не пройдёт все шаги.

## Игра

Вы — пилот спасательного корабля «Кеплер», которого сопровождает бортовой ИИ Лира. Сеть маяков Lumen замолчала. В пяти главах нужно восстановить пятнадцать узлов, собрать записи пропавших экипажей и решить, что делать с эхом, которое отвечает из сети.

Каждый из пяти циклов глав включает активацию ретрансляторов, поиск кристаллов памяти и оборону узла. Прогресс сохраняется после миссий. Удар врага снимает единицу корпуса; рывок даёт краткую неуязвимость.

## Управление

- **WASD / стрелки** — пилотирование
- **Space** — рывок
- **F** — активировать узел рядом с кораблём
- **Esc** — пауза
- **M** — переключить звук
- **Enter / Space** — подтвердить действие в меню

Windows 10/11 x64, графический драйвер с OpenGL 3.3. Проект использует Godot Compatibility renderer. Портативность, системные зависимости и запуск без сети проверяются на Windows runner до публикации первого релиза.

## Сборка и тесты

Для разработки нужны Godot 4.7.2 и официальные Windows export templates. Игроку не потребуется редактор Godot: CI собирает EXE со встроенными ресурсами и упаковывает его в ZIP.

```powershell
godot --headless --path . --quit-after 3
godot --headless --path . --script res://tests/smoke_test.gd
godot --headless --path . --export-release "Windows Desktop" build/LumenDrift.exe
```

В workflow также проверяются x64 PE-заголовок, запуск экспортированного приложения и наличие EXE в portable ZIP. Автоматический smoke-test не заменяет визуальное QA и измерение времени прохождения.
