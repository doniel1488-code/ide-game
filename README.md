# Lumen Drift

Небольшая законченная аркада о пилоте, который возвращает сигнал потерянному маяку. Пять секторов, процедурные карты, световые ядра, охотники и рывок для спасения в последний момент.

## Запуск

Игра не требует сборки, установки зависимостей или сетевого соединения для запуска. Откройте `index.html` в современном браузере или поднимите простой локальный сервер из корня проекта:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Шрифты загружаются из Google Fonts, если есть подключение; при его отсутствии используются системные шрифты. Весь игровой код и графика работают локально.

## Управление

- **WASD** или **стрелки** — двигаться.
- **Пробел** — рывок с короткой неуязвимостью (перезарядка 1,15 секунды).
- **Esc** — пауза и продолжение.
- Кнопка **♫ ЗВУК** включает и выключает процедурные звуковые сигналы.

## Игровой цикл

Соберите шесть ядер в каждом секторе, уклоняясь от охотников, затем коснитесь активированного портала. Всего нужно пройти пять секторов. У игрока три жизни; столкновение отбрасывает его и даёт время на восстановление. Карта и позиции противников меняются при каждом запуске. Лучший счёт сохраняется в браузере.

## Реализация

Самодостаточная браузерная игра на Canvas 2D и чистом JavaScript, без runtime-зависимостей и внешних игровых ресурсов. Адаптивный интерфейс рассчитан на настольные и узкие экраны. GitHub Actions проверяет синтаксис JavaScript при каждом push и pull request.
